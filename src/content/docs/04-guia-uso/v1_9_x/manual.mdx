Al entrar en este modo, se muestran dos pantallas de selección de acciones, que se pueden recorrer con las teclas **SUBIR / BAJAR** para seleccionar la acción deseada.  
Presionando **INICIO** se ejecuta el ciclo que está marcado con el signo `>`.  

Mientras se ejecuta la acción, la opción se marca con `█` y se puede presionar **PARADA** para detenerla.  
Al costado derecho de la pantalla se visualizará un contador con el tiempo que estuvo esa etapa en ejecución.  

Al presionar **CANCELAR** se vuelve al menú anterior en ambas pantallas.

---

## Primera pantalla

![Manual 1](/images/fw/v1.9.x/pantalla-manual1.png)

Seleccione la acción deseada y presione **INICIO** para ejecutarla.  
*(Salvo para **BAJAR PUENTE**, la acción se mantendrá en ejecución hasta presionar **PARADA**).*

![Manual 2](/images/fw/v1.9.x/pantalla-manual2.png)

La opción seleccionada se marca con `█` indicando que se está ejecutando dicha etapa. Presione **PARADA** para detenerla.

---

## Segunda pantalla

Esta pantalla aparece al desplazarse hacia abajo presionando **BAJAR** desde el último ciclo de la primera pantalla. Funciona de la misma manera que la primera, pero con otras acciones disponibles.  

* Al subir presionando **SUBIR** desde el primer ciclo, se vuelve a la primera pantalla.  
* Al bajar presionando **BAJAR** desde el último ciclo, también se vuelve a la primera pantalla.  

![Manual 3](/images/fw/v1.9.x/pantalla-manual3.png)

Seleccione la acción deseada y presione **INICIO** para ejecutarla.  
*(Salvo para **SUBIR PUENTE**, la acción se mantendrá en ejecución hasta presionar **PARADA**).*

### Llenado manual

Esta etapa abre las electroválvulas (EV) del producto para comenzar el llenado a contrapresión. En la pantalla se muestra el estado de cada EV como una botella llena o vacía:
* Si la muestra **vacía**, indica que la EV está cerrada.
* Si la muestra **llena**, indica que la EV está abierta.

![Manual 4](/images/fw/v1.9.x/pantalla-manual4.png)

Durante el llenado, se pueden abrir/cerrar las válvulas de llenado del producto individualmente con las teclas del control. Cada tecla corresponde a un pico:

| Tecla Control | Pico Asignado |
| :--- | :--- |
| **CANCELAR** | Pico 1 |
| **SUBIR** | Pico 2 |
| **BAJAR** | Pico 3 |
| **OK** | Pico 4 |

![Manual 5](/images/fw/v1.9.x/pantalla-manual5.png)

Al finalizar el llenado:
* Presione **PARADA** para salir sin guardar.
* Presione **INICIO** para guardar los valores calculados de los sensores. La pantalla mostrará una confirmación o el resultado del cálculo.

![Manual 6](/images/fw/v1.9.x/pantalla-manual6.png)
![Manual 7](/images/fw/v1.9.x/pantalla-manual7.png)

:::tip[Uso del Modo Manual]
Este modo es ideal para realizar pruebas iniciales, purgar las líneas de producto/gas y determinar los tiempos óptimos antes de configurar el **[Modo Automático](/04-guia-uso/v1_9_x/automatico)**[cite: 1].
:::
