## Seteo de sensores

Esta pantalla se utiliza para calibrar los umbrales de los sensores de nivel de producto, necesarios para el corte automático en el **[Modo Automático](/04-guia-uso/v1_9_x/automatico)**.

![Seteo 2](/images/fw/v1.9.x/pantalla-set2.png)

* **L** = Lectura actual en tiempo real del sensor (valor ADC, de 0 a 999).
* **S** = Nivel de seteo (umbral de comparación configurado).

Con **OK** se desplaza entre los 4 sensores y con **SUBIR / BAJAR** se ajusta el valor del umbral (`S`).  
Si la lectura en tiempo real (`L`) es **menor** al umbral seteado (`S`), el control interpreta que la botella está llena y cierra la electroválvula correspondiente.

:::note[Comportamiento de la lectura]
* **Valor alto:** El sensor no detecta producto (botella vacía/aire).
* **Valor bajo:** El sensor detecta la presencia de líquido (botella llena).

El valor del umbral **S** debe fijarse en un punto intermedio entre ambas lecturas para garantizar una detección precisa.
:::

:::tip[Procedimiento de calibración recomendado]
1. Tome un vaso con el producto a llenar.
2. Tome la lectura `L` del sensor con el pico al aire (fuera del vaso).
3. Tome la lectura `L` introduciendo el pico dentro del vaso con líquido.
4. Ajuste el umbral `S` en un valor intermedio entre ambas lecturas obtenidas.
:::

## Tiempos de limpieza

En esta pantalla se configuran los tiempos de apertura de cada electroválvula durante el ciclo automático de limpieza[cite: 1].

![Seteo 3](/images/fw/v1.9.x/pantalla-set3.png)

Cada valor representa el tiempo (en segundos) que permanecerá abierta la electroválvula correspondiente a cada circuito.  
Ajuste según el producto de limpieza/sanitizante utilizado y la longitud de las mangueras de su instalación.

Con **OK** se desplaza entre los diferentes campos de tiempo y con **SUBIR / BAJAR** se modifica el valor en segundos.
